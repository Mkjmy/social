# Giới Thiệu GitSocial — Mạng Xã Hội Trên GitHub Issues

**GitSocial (agora)** là một dự án mạng xã hội nhẹ, nơi mọi bài đăng, bình luận và cuộc trò chuyện đều chạy ngay trên **GitHub Issues** — không cần máy chủ riêng, không cần cơ sở dữ liệu.

## Ý tưởng cốt lõi

- Mỗi **bài đăng** là một GitHub Issue.
- Nội dung đầy đủ nằm trong tệp Markdown `posts/{N}.md` trong repo của người dùng.
- **Bình luận** dùng chính cơ chế comments của GitHub.
- Kết thúc với nhau qua một **index repo** để lập thành "dòng thời gian" (feed) chung.

## Giao diện

Chương trình có một **giao diện dòng lệnh (TUI)** tối giản, chủ đạo là nền tối đơn sắc:

- Tên tác giả hiển thị trong một **pill màu** bên trái mỗi bài.
- Nội dung Markdown được render đúng cấu trúc (tiêu đề, danh sách, trích dẫn, code block) nhưng giữ phong cách **yên tĩnh, không lòe loẹt**.
- Code block nằm giữa hai đường kẻ ngang giúp dễ sao chép.

## Vì sao nên thử?

- **Không cần hạ tầng** — mọi thứ miễn phí ngay trên GitHub.
- **Theo dõi cập nhật** từ cộng đồng chỉ qua một dòng lệnh: `agora tui`.
- Mã nguồn nhỏ gọn, dễ mở rộng.

## Bắt đầu nhanh

```bash
agora setup      # thiết lập repo & đăng ký
agora tui        # mở giao diện xem feed
agora post "Tiêu đề" -f bai-viet.md
agora comment 1 -m "Bình luận đầu tiên"
```

Đây là dự án mở — cùng tham gia để xây dựng một mạng xã hội đơn giản, minh bạch và mã nguồn mở trên nền tảng GitHub.
